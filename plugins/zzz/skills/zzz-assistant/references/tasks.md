# 应用对象与组合

一条龙的应用是已注册的业务单元，组合入口可以在宿主自身流程中串联多个行为。目录中的应用不一定都可以独立运行，内部应用与面向用户的入口应按当前声明区分；不能因看见内部名称就直接提交。

用户要求运行一个现有组合时，应核对其实际包含内容和保存设置，不默认拆成逐个底层应用；用户只点名一个独立目标时，也不能用范围更大的组合替代。组合、分组标签与应用之间的关系来自宿主声明，不按命名猜测。

相同应用可以与不同账号实例、配置组配合。任务名称相同并不证明它们使用相同配置，也不能从界面默认选中项推断用户指的是哪个账号。需要具体选择时先看现场对象，只有无法自行确定的必要取舍才询问。

宿主当前运行上下文与应用工厂的登记清单是不同事实：已登记不证明配置已加载或游戏已就绪；未在运行也不证明上一次成功。当前桥不等于宿主所有功能的通用调用器。

具体定位与执行读取 zzz-operator 的应用、实例及执行资料。应用标识、分组和账号选择从本次目录与契约取得，不从技能或历史运行记录复制。
