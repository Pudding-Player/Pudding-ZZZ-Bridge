# 连接与现场

Pudding 能访问桥、桥找到一条龙的现有运行上下文、应用已经初始化、对应游戏账号就绪，是相互有关但不同的条件。不能把桥连通说成游戏已准备好，也不能从游戏未开反推出配置查询不可用。

按本次错误区分不可达、鉴权、宿主上下文不存在、多个对象导致无法定位、版本不兼容及界面线程忙碌。连接失败不能证明进程不存在、应用未安装或配置丢失；状态正常后的业务拒绝也不是重连依据。

桥依附于用户已有的一条龙界面，助手不运行注入器、另起宿主、初始化新上下文或扫描其他端口。人工连接说明只在确需处理相应问题时引用，不作为正常任务的固定前置步骤。

排队未执行与执行中超时要按真实回执区分。后者结果未知时不能重复运行或保存；确认停止状态也不代表所有后台工作线程已经结束。

重连、宿主重启、目录更新或账号上下文变化后重新读取必要对象与版本，不能把旧引用当成新会话的执行依据。明确不可用时说明阻碍并结束，不转到其他游戏的桥冒充执行。
