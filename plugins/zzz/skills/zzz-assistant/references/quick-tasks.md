# 快捷入口与顺序

只封装用户已指定的应用、账号实例和配置组。保存前从当前目录核对目标、当前启用内容及执行契约；绑定稳定的业务对象，让需要的只读准备在运行时按现行协议取得，不保存旧目录版本、临时运行记录或界面对象。

宿主已有完整组合能满足目标时优先使用，不默认拆开内部应用。用户明确组合多个独立动作时，保留顺序、重复项和间隔，不把它们改成并发运行；同一宿主上下文可能共用游戏控制和运行状态。

“前项完成后”需要对应应用的业务完成证据，不是线程池接纳或启动确认。当前绑定若只能提交后台运行，不能宣称已经支持完成等待、可靠串联或无人值守；应指出缺少的等待或结果传递环节，而不是用固定时长代替。

只保存时不试跑，也不为取得配置而擅自打开页面或初始化对象。修改已有入口保留身份及其他动作；后续执行按当前配置读取，目标删除或契约不兼容时如实失败，不换成同名的其他账号、分组或应用。
