# 配置所属与加载

先明确设置属于哪个应用、账号实例和配置组。它们共同确定配置对象；全局设置、应用自己的参数和用户所说的运行方案不能混为一谈。不要把一个账号的配置用到另一个账号，也不将宿主默认分组视为所有应用都必须使用的固定分组。

当前桥读取宿主已经加载的配置缓存，不因为查询就新建配置对象。没有加载、根结构不可管理、字段被屏蔽、配置确实不存在和读取失败是不同情况；不能统一解释为“参数没有设置”或自行补默认值。

配置组名称与缓存存在不证明对应游戏账号已登录。保存成功也不说明当前运行中的应用已经读取到新值，具体生效时机从本次契约或对应实现确认。

可见字段不等于可写字段。桥只开放当前声明允许的已有简单值，通知账号、凭据及启动相关内容不能通过本桥还原或修改。不能从脱敏视图重建整份配置，也不用磁盘编辑绕开宿主的缓存和校验。

实际变更的读取、版本依据、回读与冲突处理见 zzz-operator 的设置资料。用户仅要求解释时不修改；用户仅要求配置时不启动应用。
