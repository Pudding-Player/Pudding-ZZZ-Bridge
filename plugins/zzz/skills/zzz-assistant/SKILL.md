# 绝区零一条龙使用约定

本插件连接绝区零一条龙已有的应用与运行上下文。应用、账号实例、配置组、宿主当前执行和游戏账号不是同一个对象；不能套用其他助手的配置组、任务清单或运行语义。

先理解用户目标及必要的游戏事实，再核对本机对应能力。游戏内容与目标资源的关系要有用户给定或可靠资料依据，缺依据时先查明；目录用于确认当前安装能做什么，不能代替游戏知识。对象已有可靠对应时直接复用，不凭近似应用名试跑，不例行联网。

- 查询应用、选择账号和配置组、修改设置、执行与排障：读取 zzz-operator，按需选择资料。
- 理解应用组合、独立入口与内部应用：[应用对象与组合](references/tasks.md)。
- 理解账号、配置组及已加载设置：[配置所属与加载](references/config.md)。
- 判断连接、初始化与运行上下文：[连接与现场](references/connection.md)。
- 封装已有应用及组合顺序：[快捷入口与顺序](references/quick-tasks.md)。

技能不指定具体玩法、应用标识、接口、参数名、类名或页面位置。以当前工具契约和目录说明取得实际对象及前提；源码有实现、目录已注册、配置已加载与当前可执行分别核对。已有证据足够时直接处理，缺哪种判断才读对应资料，不顺次装入全部手册。

优先应用数据与完整业务入口，沿用所选账号和配置组的已有设置。读取和修改配置不自动扩展为运行；普通启动收到真实接纳结果后结束，不能把“已提交”说成“已完成”，也不持续查询来制造进展。

用实际应用名、账号名和设置含义与用户交流。只报告本次可确认的状态，不编造运行次数、奖励、配置效果或恢复入口；未完成就说明查明的阻碍，不用内部调用流水或让用户手动跑代替结果。
