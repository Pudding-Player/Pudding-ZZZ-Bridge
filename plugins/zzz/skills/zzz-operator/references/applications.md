# 应用目录

应用清单描述一条龙已经登记的业务入口。先核对候选的用途、是否可独立运行、是否属于宿主组合及其所需配置，不能仅凭名字相似或登记顺序选择。

面向用户的组合可能封装了多项应用及准备、收尾逻辑。用户要求完整组合时沿用已有内容，除非明确要求才调整其中项目；用户只要求一个独立动作时，不用更大组合覆盖它。

内部应用通常依赖宿主固定入口建立上下文。看见名称、说明或配置不授予单独执行权限；当前桥拒绝独立运行时应说明适配范围，不改用内部类方法或其他入口强行调用。

同一个应用可关联不同账号实例与配置组。目录标签、业务标识、分组标签和游戏对象名称不能互相替代；实际执行范围必须连同实例和配置一起核对。

目录中没有目标、查询失败、当前版本未登记以及配置尚未加载分别处理。源码能解释应用如何实现，但不能证明当前安装已注册或能运行对应应用。
