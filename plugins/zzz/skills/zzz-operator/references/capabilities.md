# 能力边界

区分源码实现、应用注册、桥可调用与现场可运行。宿主内部存在一个方法或工具页面，不代表当前桥暴露了它；离线资料只能说明对应版本，不能作为本次调用标识。

当前适配围绕已注册应用、账号实例、运行状态及已加载配置。应用目录是本次宿主的登记事实，配置字段说明是当前对象的管理事实；它们都不能证明游戏行为已经执行。

目录未命中时核对对象含义、当前版本、查询范围及返回是否完整。已经命中候选时先读详情、独立运行限制与实例信息，不通过试跑相似名称来判断它是不是目标。

缺口应具体区分：索引或说明过期、桥尚未覆盖、上下文未初始化、配置未加载，或当前对象不能独立运行。不能把所有情况都报告成“软件不支持”，也不能根据源码声明补造反射方法名。

当前工具若没有提供画面识别、输入、资源安装、账号管理或任意配置构造能力，就不能假称本桥支持。只有现行能力明确开放时才能按其契约使用；不能借旧服务、终端、任意类调用或界面点击绕过当前边界。

遇到本轮常规目录或接口已经证实的覆盖缺口、契约变化或不可用时，才按需读取[缺口补足](gaps.md)。这不是正常操作的前置步骤。
