# 实例、账号与配置组

账号实例是一条龙中的配置单元，不等于独立进程，也不证明对应游戏账号已经登录。宿主当前使用的实例、用户点名实例与目录里可选实例应分开核对，不能用界面序号推算真实对象。

配置组决定应用读取哪套已加载设置。组名与默认行为以本次目录和契约为准，不假定所有应用使用同一组，也不把同名组跨账号共用。需要选择时先读取已有对象；只有用户意图确有多个合理解释时才提问。

执行前检查当前入口是否负责选择账号、建立上下文及等待准备。参数中可以指定实例，不代表可以擅自新建、登录、删除账号或保证游戏已经切换；缺少相关能力时明确指出范围。

同一宿主中的应用可能共享运行上下文、线程池及游戏控制。实例列表中有多个条目不证明可以并行执行；未取得互不影响的契约证据时保持用户顺序，不同时堆提交。

配置查询与运行对象的实例范围也须一致。不能为了读取一项设置自动切换整个宿主账号、重建上下文或创建未加载对象；用户要求仅配置时，不扩大为运行准备。
