# 状态与结果

当前运行状态、当前应用、最近一次应用结果和最近一次指令结果分别反映不同事实。最近结果可能来自前一个应用或手动操作；不能把它自动归到本次提交，也不能用上一条成功覆盖当前未知。

结合本次目标、账号实例、配置组、观察时刻及返回的应用身份建立对应关系。没有足够标识或版本依据时，明确结果尚不能归属；不编造独立运行记录，不把应用标识当成一次执行的记录编号。

空闲只说明当前未观察到运行，不区分尚未开始、自然结束、取消、异常和已达成目标。读取不到结果、结果尚未生成和业务失败应分开说明，不能仅从运行状态推断挑战成功或奖励到账。

接纳、开始、业务完成和停止各需相应证据。普通启动得到接纳即可结束；只有用户要求跟进时读取必要范围，避免反复查同一状态或把空结果当成需要再次运行的理由。

答复只保留用户关心的应用、账号及真实阶段。游戏进度、耗时、收益和失败根因没有对应结果支持时不作为事实；只说当前能确认和仍不确定的部分。
